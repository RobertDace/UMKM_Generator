# KilasNota — AI UMKM Admin Companion

Aplikasi asisten administrasi UMKM cerdas berbasis **Next.js & Tailwind CSS** yang dirancang untuk mempercepat pencatatan pesanan dari chat WhatsApp, pembuatan invoice instan, dan pelacakan inventaris stok barang secara otomatis.

---

## ⚡ Fitur Utama

1. **Smart WA Chat Parser**:
   - Salin dan tempel (*copy-paste*) format orderan mentah dari pelanggan WhatsApp.
   - Ekstraksi otomatis nama pembeli, alamat pengiriman, dan daftar produk yang dipesan.

2. **Instant Invoice Generator**:
   - Menghasilkan nota/invoice digital siap kirim dan cetak.
   - Format rapi dan profesional untuk meningkatkan kepercayaan pelanggan.

3. **Inventory Management**:
   - Pengurangan stok produk secara otomatis setelah transaksi dikonfirmasi.
   - Ringkasan status ketersediaan barang.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19, Framer Motion
- **Styling**: Tailwind CSS & Lucide Icons
- **Language**: TypeScript

---

## 🚀 Panduan Memulai

```bash
# 1. Clone repository
git clone https://github.com/RobertDace/UMKM_Generator.git

# 2. Masuk ke direktori proyek
cd UMKM_Generator

# 3. Pasang dependensi
npm install

# 4. Jalankan server lokal
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di peramban Anda.
